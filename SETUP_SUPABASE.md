# Подготовка Supabase

Проект использует обычные браузерные ES-модули без npm и сборщика. Клиент Supabase подготовлен отдельно и пока не подключён к текущей точке входа сайта.

## Где хранятся параметры проекта

Публичные параметры подключения находятся в `js/supabase/config.js`:

- `SUPABASE_URL` — на Project URL из настроек проекта Supabase;
- `SUPABASE_PUBLISHABLE_KEY` — на Publishable Key проекта.

Текущая конфигурация уже заполнена. При смене проекта или ротации ключа обновляйте значения в этом файле и используйте только публичный Publishable Key, предназначенный для браузера.

## Какие данные нельзя использовать

Никогда не помещайте в `config.js`:

- Secret Key;
- `service_role` key;
- Database Password;
- любые другие серверные секреты.

Код браузерного сайта и его конфигурация доступны посетителям. Secret Key и `service_role` обходят ограничения Row Level Security и допустимы только в защищённом серверном окружении.

## Как подготовлен клиент

Файл `js/supabase/client.js`:

1. загружает `@supabase/supabase-js@2` через CDN как ES-модуль;
2. получает Project URL и Publishable Key из `config.js`;
3. создаёт и экспортирует единственный экземпляр `supabase`.

В этом файле не должно быть запросов, преобразования данных или другой бизнес-логики.

## Как будет происходить дальнейшее подключение

На следующем этапе отдельный модуль работы с данными сможет импортировать готовый клиент:

```js
import { supabase } from "./supabase/client.js";
```

После этого запросы к таблицам будут добавляться в отдельные модули и подключаться к приложению только после подготовки схемы базы, Row Level Security и необходимых политик.

Сейчас `client.js` не импортируется из `js/script.js`, поэтому:

- сайт продолжает получать каталог из `tracks.js`;
- Supabase SDK не загружается при открытии сайта;
- соединение с Supabase не создаётся;
- отображение, поиск, рекомендации и плеер не изменяются.

## SQL-миграции

Будущие SQL-миграции следует добавлять в:

```text
supabase/migrations/
```

Первая подготовленная миграция и инструкция по её ручному применению описаны в `supabase/README.md`. Миграция не применяется автоматически.
